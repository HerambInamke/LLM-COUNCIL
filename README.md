# LLM Council

> A multi-agent AI system that combines responses from multiple Large Language Models, enables peer review between them, and generates a consensus answer through a chairman model.

---

## Overview

LLM Council is a full-stack application that explores collaborative reasoning between multiple AI models.

Instead of relying on a single language model, the application sends a user's prompt to multiple LLMs simultaneously, allows each model to evaluate the others anonymously, and produces a final synthesized response generated by a designated Chairman model.

The goal is to reduce hallucinations, compare reasoning styles, and provide higher-quality responses through consensus rather than individual opinions.

---

## Features

- Multi-model parallel inference
- Anonymous peer review between LLMs
- AI-generated ranking based on quality and reasoning
- Chairman model synthesizes the final response
- Individual model responses available for comparison
- Persistent conversation history
- Clean ChatGPT-inspired interface
- Configurable model council

## How It Works

### Stage 1 — Independent Reasoning

The user's prompt is sent to every selected LLM concurrently.

Each model generates an independent response without knowledge of the others.

Example:

```
User Prompt
        │
        ▼
 ┌──────────────┐
 │ GPT-5.1      │
 ├──────────────┤
 │ Claude       │
 ├──────────────┤
 │ Gemini       │
 ├──────────────┤
 │ Grok         │
 └──────────────┘
```

---

### Stage 2 — Cross Review

Each model receives every other response.

Model identities are removed before evaluation to eliminate provider bias.

Every model scores the remaining responses based on:

- Accuracy
- Completeness
- Reasoning quality
- Helpfulness

---

### Stage 3 — Consensus Generation

The Chairman model receives:

- Original prompt
- Every first response
- Peer-review rankings

It synthesizes these into one final answer representing the council's collective reasoning.

```
Responses
      │
Peer Reviews
      │
      ▼
 Chairman Model
      │
      ▼
 Final Consensus
```

```bash

```

---

### Backend

```bash
uv sync
```


## Configuration

Configure your council in:

```
backend/config.py
```

Example

```python
COUNCIL_MODELS = [
    "openai/gpt-5.1",
    "anthropic/claude-sonnet-4.5",
    "google/gemini-3-pro-preview",
    "x-ai/grok-4",
]

CHAIRMAN_MODEL = "google/gemini-3-pro-preview"
```

## Why This Project

Most AI applications rely on a single model, making responses dependent on one system's strengths and weaknesses.

LLM Council explores an alternative approach where multiple specialized models collaborate, critique one another, and collectively produce a higher-confidence answer.

The project serves both as a practical AI assistant and as an exploration of multi-agent reasoning systems.
